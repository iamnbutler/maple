# Static reference data

Immutable MapleStory (GMS 2026) reference data lives here as `as const` TypeScript
modules or generated JSON. Nothing in this directory is user data — anything
written at runtime belongs in the repo-root `data/` directory, accessed through
`$lib/store`.

**World scope: Heroic (Reboot) only.** Where a table or a cost differs by world
type, only the Heroic variant is implemented, and the module says so in a comment
(cube prices in mesos, Heroic boss crystal payouts, `BONUS_POTENTIAL_AVAILABLE_IN_HEROIC = false`,
Arcane Catalyst unavailable, Powerful Rebirth Flames bought from General Stores).

## Rules for this directory

1. **No number without a source.** Every table carries an inline comment citing the
   research section (`formulas.md §…` / `bosses.md §…`) plus the original URL.
2. **Nothing invented.** Where no public source documents a value, the export is
   named `UNVERIFIED_*` and consumers must opt in explicitly (see below).
3. **Formulas over tables** where the research publishes an exact formula — but the
   tabulated values are still asserted in the `*.spec.ts` next to the module.

## UNVERIFIED values

Anything the research could not source is exported behind an `UNVERIFIED_*` name and
is inert unless the caller opts in:

| Export                                  | Module         | Why                                                                                                                                                                                                                              |
| --------------------------------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `UNVERIFIED_WEAPON_26_30`               | `starforce.ts` | No public source documents weapon ATT/MATT for stars 26-30. The table is one community `+1/star` extrapolation. `starStatGain` / `cumulativeStarStats` **throw** unless `allowUnverifiedWeapon26to30` is passed.                 |
| `UNVERIFIED_ENHANCEMENT_MODES`          | `starforce.ts` | Nexon published no rates or cost multipliers for GMS v269 Enhancement Modes. Mode 1 is standard; modes 2 and 3 are `null` (nothing to model); mode 4 comes from a namu.wiki snippet. Requires `allowUnverifiedEnhancementModes`. |
| `UNVERIFIED_ABYSSAL_FLAME_DISTRIBUTION` | `flames.ts`    | The Abyssal Rebirth Flame's tier distribution is described only qualitatively.                                                                                                                                                   |
| `UNVERIFIED_GLOVE_CRIT_DAMAGE`          | `potential.ts` | `formulas.md` says gloves get a Critical Damage line but gives no value. The +8% Legendary figure is the community value, **not sourced in the research**.                                                                       |
| `UNVERIFIED_GMS_RANK_UP_RATES`          | `potential.ts` | The published GMS cube rank-up rates predate the v239 cube revamp, which also changed tier-up probabilities.                                                                                                                     |
| `UNVERIFIED_BONUS_POTENTIAL_RATES`      | `potential.ts` | Only KMS numbers are published; GMS is stated to be higher. Moot in Heroic worlds anyway.                                                                                                                                        |

Two further soft flags, documented in comments rather than in the export name:
the level-300 hyper-stat award of 19 points (StrategyWiki only), and the 0★-15★ GMS
meso-cost divisors, which may predate the v264 cost adjustment.

## Conflicts resolved in these tables

- **Max stars at level 95** — two wikis say 95-107 → 8★; `masonym.dev` says 96. We use 95.
- **Weapon 17★ delta** — the wiki's delta table repeats the 16★ value; its own cumulative
  table and two open-source implementations give +7/+8/+9. We use the corrected deltas.
- **Weapon 25★ / Lv200-249** — the wiki cell renders +102 MATT; the delta chain and
  StrategyWiki both give +207. Corrected.
- **Badge cumulative cells** — 16★/250 (59) and 21★/150-159 (104) contradict their own
  per-star deltas. We compute `40 + perStar × (★ − 15)` (57 and 106).
- **Flame single-stat step at item levels 220-229** — the published closed form
  (`min(⌊lvl/20⌋, 11) + 1`) yields 12 while the published table says 11. We follow the
  **table** (two independent sources carry it); see the comment on `flameSingleStat`.
- **Potential level breakpoint** — GMS/TMS is **151**, not the 201 several guides quote.
- **Hyper stat cost curve** — 550 to max, not the widely repeated 180.
- **Arcane weekly Special Content** — 40 symbols per clear (StrategyWiki's 15 is stale).
